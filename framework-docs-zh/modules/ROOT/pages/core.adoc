[[spring-core]]
= 核心技术

参考文档这部分涵盖了 Spring 框架绝对不可或缺的技术。

其中最重要的就是 Spring 框架的控制反转（IoC）容器。在对 Spring 框架的控制反转（IoC）全面阐述之后，是对 Spring 的面向切面编程（AOP）技术的详尽介绍。Spring 框架有自己的 AOP 框架，它概念上很容易理解，并且能够成功的满足 Java 企业级编程中 80% 的 AOP 需求。

同时也提供了 Spring 与 AspectJ（目前最丰富的 AOP 实现，也是 Java 企业空间中最成熟的 AOP 实现） 的集成。

AOT 处理可以用于优化您的应用程序。它通常用于使用 GraalVM 部署原生映像。
