[[beans-factory-dependson]]
= 使用 `depends-on`

如果一个 Bean 是另一个 Bean 的依赖，这通常意味着一个 Bean 被设置为另一个 Bean 的属性。通常，你可以通过 XML
元数据中的 xref:core/beans/dependencies/factory-properties-detailed.adoc#beans-ref-element[`<ref/>` 元素]
或通过 xref:core/beans/dependencies/factory-autowire.adoc[autowiring] 来实现这一点。

然而，有时 Bean 之间的依赖关系并不那么直接。一个例子是当类中的静态初始化器需要被触发时，例如用于数据库驱动注册。
`depends-on` 属性或 `@DependsOn` 注解可以显式强制一个或多个 Bean 在使用此元素的 Bean
被初始化之前完成初始化。以下示例使用 `depends-on` 属性来表达对单个 Bean 的依赖：

[source,xml,indent=0,subs="verbatim,quotes"]
----
	<bean id="beanOne" class="ExampleBean" depends-on="manager"/>
	<bean id="manager" class="ManagerBean" />
----

要表达对多个 bean 的依赖，可以将 bean 名称列表作为 `depends-on` 属性的值提供（逗号、空格和分号都是有效的分隔符）：

[source,xml,indent=0,subs="verbatim,quotes"]
----
	<bean id="beanOne" class="ExampleBean" depends-on="manager,accountDao">
		<property name="manager" ref="manager" />
	</bean>

	<bean id="manager" class="ManagerBean" />
	<bean id="accountDao" class="x.y.jdbc.JdbcAccountDao" />
----

NOTE: `depends-on` 属性既可以指定初始化时的依赖关系，也可以（在仅针对
xref:core/beans/factory-scopes.adoc#beans-factory-scopes-singleton[单例] bean
的情况下）指定相应的销毁时的依赖关系。与给定 bean 定义 `depends-on` 关系的依赖 bean 会先于该 bean
本身被销毁。因此，`depends-on` 也可以控制关闭顺序。
