[[beans-factory-lazy-init]]
= Beans 懒加载

默认情况下，`ApplicationContext` 实现会在初始化过程中急切地创建并配置所有
xref:core/beans/factory-scopes.adoc#beans-factory-scopes-singleton[单例]
bean。通常，这种预实例化是可取的，因为配置或周边环境中的错误会立即被发现，而不是在数小时甚至数天后才暴露。当这种行
为不合需要时，您可以通过将 bean 定义标记为延迟初始化来阻止单例 bean 的预实例化。延迟初始化的 bean 会告知 IoC
container 在首次请求时才创建 bean 实例，而非在启动时创建。

当上述配置被 `ApplicationContext` 消费时，`lazy` bean 不会在 `ApplicationContext` 启动时被急切地预实例化， 而 `notLazy` 则会被急切地预实例化。

然而，当一个懒初始化的 bean 是某个非懒初始化的单例 bean 的依赖时，`ApplicationContext` 会在启动时创建该懒初始化的 bean，因为它必须满足单例 bean 的依赖关系。该懒初始化的 bean 会被注入到其他非懒初始化的单例 bean 中。
